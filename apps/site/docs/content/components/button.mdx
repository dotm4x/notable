## Installation

```bash
pnpm add @dotm4x/one
```

Import the styles once in your app:

```tsx
import '@dotm4x/one/styles.css';
```

## Usage

```tsx
import { Button } from '@dotm4x/one/components';

export function Example() {
  return <Button>Click me</Button>;
}
```

## API Reference

### Button

| Prop       | Type                                                                       | Default     | Description                               |
| ---------- | -------------------------------------------------------------------------- | ----------- | ----------------------------------------- |
| `variant`  | `'primary' \| 'secondary' \| 'outline' \| 'ghost' \| 'danger'`             | `'primary'` | Visual appearance.                        |
| `size`     | `'small' \| 'medium' \| 'large' \| 'icon' \| 'icon-small' \| 'icon-large'` | `'medium'`  | Button size.                              |
| `disabled` | `boolean`                                                                  | `false`     | Disables interaction.                     |
| `asChild`  | `boolean`                                                                  | `false`     | Renders child element with button styles. |
| `children` | `ReactNode`                                                                | —           | Button content.                           |

## Accessibility

- Use an accessible name for icon-only buttons via `aria-label`.
- Set `aria-busy="true"` and disable the button while loading.
- Buttons default to `type="button"` to avoid accidental form submission.
