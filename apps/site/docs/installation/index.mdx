One is distributed as a single package with entry points for components, icons, and styles.

## Install the package

<PackageManagerTabs
  pnpm="pnpm add @dotm4x/one"
  npm="npm install @dotm4x/one"
  yarn="yarn add @dotm4x/one"
  bun="bun add @dotm4x/one"
/>

React and React DOM 18 or 19 are required as peer dependencies.

## Import the styles

Import the shared styles once in your application entry point:

```tsx
import '@dotm4x/one/styles.css';
```

This includes the design tokens, component styles, and the system font.

## Render a component

```tsx
import { Button } from '@dotm4x/one/components';

export function Example() {
  return <Button>Click me</Button>;
}
```

## Import icons

Icons come from a separate entry point:

```tsx
import { Button } from '@dotm4x/one/components';
import { Plus } from '@dotm4x/one/icons';

export function AddButton() {
  return (
    <Button>
      <Plus aria-hidden="true" />
      Add item
    </Button>
  );
}
```

## Package structure

| Entry point              | Contents                                            |
| ------------------------ | --------------------------------------------------- |
| `@dotm4x/one/components` | React components, the data table, and highlighting. |
| `@dotm4x/one/icons`      | The icon set as React components.                   |
| `@dotm4x/one/styles.css` | Design tokens and shared styles.                    |
