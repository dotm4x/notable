One is a design language for creating expressive, coherent, accessible, and
thoughtfully crafted digital experiences. It defines shared principles,
foundations, patterns, and component guidance that can be realized through
multiple implementations.

This site documents the web implementation of One: its React components,
their APIs, and usage guidance.

## Start here

- **Install the package** to add One to an existing project.
- **Browse the components** to see available building blocks and their APIs.
- The **design guidelines** in the repository explain the reasoning behind the
  system.

## A shared language

One is not a single component library. It is the shared source of truth for
design decisions, so every implementation can preserve the same intent while
following the conventions of its platform.

The web implementation lives in `@dotm4x/one`. The guidelines live in the
repository and remain independent from any one implementation.
