One is a design language for expressive, coherent, and accessible interfaces. It defines shared principles, foundations, patterns, and component guidance that implementations realize on their own platforms.

This site documents the web implementation, `@dotm4x/one`: its React components, their APIs, and usage guidance.

## Start here

- Install the package to add One to an existing project.
- Browse the components to see the available building blocks.
- Read the design guidelines in the repository for the reasoning behind the system.
