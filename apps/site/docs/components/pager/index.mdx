## Usage

```tsx
import { Pager } from '@dotm4x/one/components';

<Pager
  previous={{ href: '/docs/installation', label: 'Installation' }}
  next={{ href: '/docs/components', label: 'Components' }}
/>;
```

## API reference

### Pager

| Prop            | Type        | Default        | Description                       |
| --------------- | ----------- | -------------- | --------------------------------- |
| `previous`      | `PagerItem` | —              | Previous destination.             |
| `next`          | `PagerItem` | —              | Next destination.                 |
| `previousLabel` | `string`    | `'Previous'`   | Direction label before the title. |
| `nextLabel`     | `string`    | `'Next'`       | Direction label before the title. |
| `label`         | `string`    | `'Pagination'` | Accessible name of the landmark.  |

It renders a `nav` landmark and forwards native `HTMLElement` attributes. It
returns nothing when both destinations are omitted.

### Pager.Item

Exported as `PagerItem`.

| Property | Type     | Description         |
| -------- | -------- | ------------------- |
| `href`   | `string` | Destination URL.    |
| `label`  | `string` | Visible page title. |

## Accessibility

Each link includes its direction and destination in the accessible name, such
as “Previous: Installation”. If one side is omitted, the remaining link keeps
the full column.
