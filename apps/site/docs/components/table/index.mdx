## Usage

```tsx
import { Table } from '@dotm4x/one/components';

<Table>
  <Table.Caption>Recent payments</Table.Caption>
  <Table.Header>
    <Table.Row>
      <Table.Head>Email</Table.Head>
      <Table.Head align="end">Amount</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>ken99@example.com</Table.Cell>
      <Table.Cell align="end">$316.00</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>;
```

## API reference

### Table

| Prop                 | Type     | Default | Description                                |
| -------------------- | -------- | ------- | ------------------------------------------ |
| `containerClassName` | `string` | —       | Additional class for the scroll container. |

It renders a native `table` inside a horizontally scrollable container and
forwards native table attributes.

### Table.Caption

Renders a `caption`, announced as the table description. It has no props of its
own and forwards native caption attributes.

### Table.Header

Renders a `thead`. It has no props of its own and forwards native section
attributes.

### Table.Body

Renders a `tbody`. It has no props of its own and forwards native section
attributes.

### Table.Footer

Renders a `tfoot`. It has no props of its own and forwards native section
attributes.

### Table.Row

| Prop       | Type      | Default | Description                |
| ---------- | --------- | ------- | -------------------------- |
| `selected` | `boolean` | `false` | Marks the row as selected. |

It renders a `tr` with `data-state="selected"` when selected and forwards native
row attributes.

### Table.Head

| Prop    | Type                                    | Default   | Description                        |
| ------- | --------------------------------------- | --------- | ---------------------------------- |
| `align` | `'start' \| 'center' \| 'end'`          | `'start'` | Horizontal alignment.              |
| `sort`  | `'ascending' \| 'descending' \| 'none'` | —         | Sort state, mapped to `aria-sort`. |

It defaults to `scope="col"` and forwards the remaining native header cell
attributes. Use `align="end"` for comparable numbers.

### Table.Cell

| Prop    | Type                           | Default   | Description           |
| ------- | ------------------------------ | --------- | --------------------- |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Horizontal alignment. |

It renders a `td` and forwards the remaining native cell attributes.

## Accessibility

Always provide a caption or an accessible name for the table. Sortable headers
must expose `aria-sort`, and the visual sort indicator must not be the only
signal. The scroll container keeps wide tables usable on narrow screens.
