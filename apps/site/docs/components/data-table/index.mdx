## Usage

```tsx
import {
  DataTable,
  DataTableColumnHeader,
  type ColumnDef,
  type DataTableFeatures,
} from '@dotm4x/one/components';

const columns: ColumnDef<DataTableFeatures, Payment>[] = [
  {
    accessorKey: 'email',
    filterFn: 'includesString',
    header: ({ column }) => (
      <DataTableColumnHeader column={column} title="Email" />
    ),
    sortFn: 'text',
  },
];

<DataTable
  columns={columns}
  data={payments}
  enableRowSelection
  filterColumn="email"
/>;
```

## API reference

### DataTable

| Prop                     | Type                                    | Default                    | Description                              |
| ------------------------ | --------------------------------------- | -------------------------- | ---------------------------------------- |
| `columns`                | `ColumnDef<DataTableFeatures, TData>[]` | —                          | TanStack column definitions.             |
| `data`                   | `TData[]`                               | —                          | Rows rendered by the table.              |
| `filterColumn`           | `string`                                | —                          | Column used by the default filter input. |
| `filterPlaceholder`      | `string`                                | `Filter…`                  | Filter placeholder and accessible name.  |
| `enableRowSelection`     | `boolean`                               | `false`                    | Adds a checkbox column.                  |
| `enableColumnVisibility` | `boolean`                               | `true`                     | Shows the column visibility menu.        |
| `enablePagination`       | `boolean`                               | `true`                     | Shows pagination controls.               |
| `pageSize`               | `number`                                | `10`                       | Initial page size.                       |
| `pageSizeOptions`        | `number[]`                              | `[10, 20, 25, 30, 40, 50]` | Available page sizes.                    |
| `emptyState`             | `ReactNode`                             | —                          | Replaces the default empty state.        |
| `toolbar`                | `(table) => ReactNode`                  | —                          | Replaces the default toolbar.            |

### DataTable.ColumnHeader

Exported as `DataTableColumnHeader`. It renders a header cell whose button
toggles sorting and updates `aria-sort`.

| Prop     | Type     | Default | Description                               |
| -------- | -------- | ------- | ----------------------------------------- |
| `column` | `Column` | —       | Column whose sorting state is controlled. |
| `title`  | `string` | —       | Visible header label.                     |

### DataTable.ViewOptions

Exported as `DataTableViewOptions`.

| Prop        | Type                                   | Default  | Description                              |
| ----------- | -------------------------------------- | -------- | ---------------------------------------- |
| `table`     | `ReactTable<DataTableFeatures, TData>` | —        | Table instance created by `DataTable`.   |
| `label`     | `string`                               | `'View'` | Trigger label.                           |
| `className` | `string`                               | —        | Additional class for the trigger button. |

### DataTable.Pagination

Exported as `DataTablePagination`.

| Prop              | Type                                   | Default                    | Description                            |
| ----------------- | -------------------------------------- | -------------------------- | -------------------------------------- |
| `table`           | `ReactTable<DataTableFeatures, TData>` | —                          | Table instance created by `DataTable`. |
| `pageSizeOptions` | `number[]`                             | `[10, 20, 25, 30, 40, 50]` | Page sizes offered by the control.     |

### DataTable.features

Exported as `dataTableFeatures`.

The TanStack feature object. Pass it to the table helpers when you build a
custom toolbar, header, or pagination control.

## Accessibility

The table uses native table semantics. `DataTableColumnHeader` toggles sorting
through a button, and the header cell exposes `aria-sort`. The selection column
uses native checkboxes. Filtering has a visible label through its placeholder
and an accessible name, and the empty state is announced in the table.
