## API reference

### Button

| Prop       | Type                                                                       | Default     | Description                               |
| ---------- | -------------------------------------------------------------------------- | ----------- | ----------------------------------------- |
| `variant`  | `'primary' \| 'secondary' \| 'outline' \| 'ghost' \| 'danger'`             | `'primary'` | Visual appearance.                        |
| `size`     | `'small' \| 'medium' \| 'large' \| 'icon' \| 'icon-small' \| 'icon-large'` | `'medium'`  | Button size.                              |
| `disabled` | `boolean`                                                                  | `false`     | Disables interaction.                     |
| `asChild`  | `boolean`                                                                  | `false`     | Renders child element with button styles. |
| `children` | `ReactNode`                                                                | —           | Button content.                           |

`Button` forwards native `<button>` attributes and Motion props; the table
lists only its own props.

## Accessibility

<Callout title="Accessible button names">
  Use an accessible name for icon-only buttons via `aria-label`. Set
  `aria-busy="true"` and disable the button while loading.
</Callout>

- Buttons default to `type="button"` to avoid accidental form submission.
- Disabled buttons use the native `disabled` attribute and are removed from the
  tab order. Do not hide essential information behind a disabled control.
