## Usage

```tsx
import { DatePicker } from '@dotm4x/one/components';

<DatePicker
  aria-label="Start date"
  locale="en-US"
  onValueChange={(date) => console.log(date)}
/>;
```

## API reference

### DatePicker

| Prop             | Type                      | Default           | Description                                              |
| ---------------- | ------------------------- | ----------------- | -------------------------------------------------------- |
| `value`          | `Date \| null`            | —                 | Selected date for controlled use.                        |
| `defaultValue`   | `Date \| null`            | `null`            | Selected date when uncontrolled.                         |
| `onValueChange`  | `(date: Date) => void`    | —                 | Called with the newly selected date.                     |
| `open`           | `boolean`                 | —                 | Controlled open state of the calendar popup.             |
| `defaultOpen`    | `boolean`                 | `false`           | Initial open state when uncontrolled.                    |
| `onOpenChange`   | `(open: boolean) => void` | —                 | Called with the requested open state.                    |
| `disabled`       | `boolean`                 | `false`           | Disables the trigger so the calendar cannot open.        |
| `readOnly`       | `boolean`                 | `false`           | Shows the selected date without allowing a change.       |
| `minDate`        | `Date`                    | —                 | Earliest selectable date; only its calendar day is used. |
| `maxDate`        | `Date`                    | —                 | Latest selectable date; only its calendar day is used.   |
| `isDateDisabled` | `(date: Date) => boolean` | —                 | Returns `true` for dates that cannot be selected.        |
| `placeholder`    | `string`                  | `'Select a date'` | Text shown when no date is selected.                     |
| `locale`         | `string`                  | runtime locale    | BCP 47 locale used to format the date and the calendar.  |
| `formatDate`     | `(date: Date) => string`  | —                 | Formats the selected date in the trigger.                |

It renders a `button` trigger and forwards the remaining native button
attributes.

## Accessibility

- The trigger's accessible name includes the visible value, so `aria-label` or
  `aria-labelledby` is combined with the formatted date or placeholder.
- The popup is labelled `Choose date`, and the trigger reports its state with
  `aria-expanded`.
- The calendar icon is decorative and hidden from assistive technology.
- `disabled` sets the native `disabled` attribute, while `readOnly` keeps the
  button focusable but blocks the popup.
