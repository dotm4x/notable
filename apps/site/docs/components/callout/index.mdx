## Usage

```tsx
import { Callout } from '@dotm4x/one/components';
import { TriangleAlert } from '@dotm4x/one/icons';

<Callout tone="warning">
  <Callout.Icon>
    <TriangleAlert aria-hidden="true" />
  </Callout.Icon>
  <Callout.Content>
    <Callout.Title>Review required</Callout.Title>
    <p>Check the settings before continuing.</p>
  </Callout.Content>
</Callout>;
```

## API reference

### Callout

| Prop       | Type                                           | Default  | Description               |
| ---------- | ---------------------------------------------- | -------- | ------------------------- |
| `tone`     | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` | Semantic tone.            |
| `role`     | `'note' \| 'status' \| 'alert'`                | `'note'` | Accessible role.          |
| `children` | `ReactNode`                                    | —        | Callout parts or content. |

`Callout` also accepts native `div` attributes.

### Callout.Icon

Renders the tone icon in a `span` hidden from assistive technology. It has no
props of its own and forwards native `span` attributes.

### Callout.Content

Renders the content column. It has no props of its own and forwards native `div`
attributes.

### Callout.Title

| Prop | Type                                   | Default | Description        |
| ---- | -------------------------------------- | ------- | ------------------ |
| `as` | `'p' \| 'div' \| 'h2' \| 'h3' \| 'h4'` | `'p'`   | Element to render. |

It forwards native `HTMLElement` attributes.

### Callout.Actions

Renders the actions region. It has no props of its own and forwards native `div`
attributes.

## Accessibility

Use `role="note"` for persistent guidance. Reserve `role="alert"` for urgent
messages that should interrupt assistive technology, and do not use a callout
for transient feedback. Use `Toast` for that.
