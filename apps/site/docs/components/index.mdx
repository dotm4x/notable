Components translate the One design language into accessible, composable React
building blocks. Each component documents its intended role, examples, API, and
accessibility expectations.

<PageList />

## Composition

Components are designed to work together. Prefer composing existing components
over recreating their behavior, and follow the shared guidelines for spacing,
color, focus, and motion.

## Installation

Every component page assumes the package is already installed and the shared
styles are imported. See [Installation](/docs/installation) if you are starting
from scratch.
