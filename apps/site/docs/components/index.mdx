Components translate the design language into accessible, composable React building blocks. Each page documents a component's role, examples, API, and accessibility expectations.

<PageList />

## Before you start

Component pages assume the package is installed and the shared styles are imported. See [Installation](/docs/installation) if you are starting from scratch.

## Composition

Components are designed to work together. Prefer composing existing components over recreating their behavior, and follow the shared guidance for spacing, color, focus, and motion.
